# OctoAcme Project Management Docs

This folder contains OctoAcme's project management process documents. This README provides a concise overview of the processes and links to the full documents to help onboarding and discoverability.

## Brief overview of OctoAcme project management processes

- Initiation: Capture the problem, stakeholders, success metrics, and decide go/no-go. Start with a Project One-pager to align stakeholders and confirm resources.
- Planning: Break approved initiatives into shippable backlog items, estimate work, define the Definition of Done (DoD), identify dependencies, and map releases and milestones.
- Execution & Tracking: Use a project board (Backlog, Ready, In Progress, In Review, QA, Done), small PRs, CI checks, daily standups, weekly delivery syncs, and track velocity and burndown.
- Release & Deployment: Prepare release notes, ensure pre-release checks and security scans pass, deploy via automated pipelines when possible, and have rollback/mitigation plans.
- Retrospective & Continuous Improvement: Run retrospectives after sprints or incidents, convert action items into backlog issues, and measure improvement.
